备份与恢复

在「设置 → 数据管理」导出完整 JSON 备份。恢复前请核对文件与预览，恢复将替换账本。iCloud 及 WebDAV 备份不等于实时同步。

恢复购买

使用原购买商店账户，进入「设置 → 哎呀 Pro → 恢复购买」。Apple 与 Google Play 权益分别管理，恢复账本不会解锁 Pro。

Backups and purchases

Export a complete JSON backup in Settings → Data management. Check the preview before restoring, which replaces ledger data. Cloud backups are not real-time sync. Restore Pro in Settings → Aiya Pro using the original store account. Apple and Google Play purchases are separate.
