哎呀记账隐私政策 更新与生效日期：2026年11月26日 适用版本：哎呀记账（iOS、iPadOS 与 watchOS） 运营者：duhaley（个人开发者） 隐私与支持邮箱：924323178@qq.com 哎呀记账是一款无需注册的个人记账工具。我们重视您的隐私。本政策说明应用处理资料的方式、您可作出的选择，以及如何联系我们。 1. 本地记账与账单导入 您输入的账户名称、币种、余额、收入、支出、自定义分类与标签、日期、备注、预算、常用模板、周期账单和偏好设置保存在设备本地，用于记账、统计和提醒。应用没有自营账本服务器，不会自动将账本发送给运营者。 您选择的 CSV / XLSX 账单在设备上解析。导入来源、交易号、商户、支付方式和文件指纹用于核对重复与保留来源，随完整 JSON 备份保存。应用不会自动向支付宝、微信或银行上传原始账单，不要求银行或支付平台密码，不读取短信、通讯录或自动抓取其他应用账单。 2. 您主动选择的备份与分享 您可以手动导出 JSON 完整备份或 CSV 文件，也可以选择自己的 iCloud Drive 或 HTTPS WebDAV 服务保存和恢复备份。这些操作由您主动发起；完整备份包含金额、账户、备注、预算、周期账单、模板、偏好和导入来源，即使界面开启了隐藏金额。当前没有后台定时备份或实时账本同步。 WebDAV 地址、用户名和密码仅用于当前备份页面会话，并发送给您指定的 HTTPS 服务；不写入账本或完整备份。iCloud 由 Apple 及您的 Apple 账户设置管理。运营者不接收您的 WebDAV 凭据，也不能通过应用访问您私人云空间中的账本。云服务和分享目标可能依其政策留存文件、IP 地址、访问时间或请求信息，请选择您信任的服务并查阅其政策。iCloud 文件可能需要等待系统完成上传或下载。 3. Pro 购买与恢复购买 哎呀 Pro 可通过 Apple 应用内购买选择永久买断或按月、按年自动续订。价格与周期以商店确认为准；可在 Apple 订阅管理中取消续费，取消后可用至已付费期间结束。永久买断不自动续费，已有买断权益继续有效；购买永久版不会自动取消现有订阅。Apple StoreKit 处理购买、恢复与交易验证，应用仅根据系统已验证的交易及有效期判断权益，包括退款、撤销及到期状态。购买不向 Apple 上传账本，权益到期不会删除账本，也不影响备份与导出。 应用不读取或保存 Apple 账户密码、支付卡号或银行支付凭据，也不会把购买凭据或 Pro 权益写入账本备份。恢复账本不会授予 Pro，已有购买可在「设置 → 哎呀 Pro」中恢复。Apple 对商店账户、交易和付款资料的处理适用其政策。 4. 可选本地通知 周期账单提醒默认关闭，仅在您主动开启时请求 iOS 通知权限。通知排程在本机进行，仅显示通用的待确认提示，不显示金额、账户或账单名称，不向运营者发送账单资料。提醒开关属于本机偏好，不包含在账本备份中。您可在应用中关闭提醒，或在系统设置中撤销通知权限。拒绝通知不影响查看账单清单。 5. 保存、安全与删除 账本以本地偏好 JSON 保存。当前版本的账本和 JSON / CSV 导出文件没有应用级加密；隐藏金额只遮挡界面显示，不是应用锁。HTTPS 保护 WebDAV 传输，但不代表文件端到端加密。请保护设备、定期备份，并妥善保管导出文件。 您可在应用中编辑、删除记录或清空本地账本。恢复备份会在校验及确认后替换当前账本。删除本地资料或卸载应用不会自动删除云备份、导出文件、收件人副本或系统备份，请在相应服务中另行管理。卸载或设备故障可能导致未备份的资料丢失。系统备份及迁移依 Apple 和您的设备设置处理。 应用没有自营用户账号，因此不需要账号注销。运营者未收到的本地资料无需通过运营者申请删除，您可直接在设备上管理。 6. 广告、跟踪与支持 应用不展示广告，不集成广告跟踪、行为分析或开发者崩溃上报服务，不出售您的个人资料。应用不请求定位、通讯录、麦克风或相机权限。文件选择和分享由系统界面及您选择的服务处理。 如果您主动发送支持邮件，我们会收到您的发件地址和您提供的内容，仅用于回复咨询、处理问题或履行必要义务。请勿发送完整账本、密码或完整银行卡资料。我们仅在处理事项所需期限内保留支持资料；无继续保留必要时删除，法律要求除外。您可通过支持邮箱提出访问、更正或删除已提供支持资料的请求。 本政策将由运营者另行选择的网站托管。网站访问日志、Cookie 和托管服务的处理方式应以该网站发布的说明为准，网站资料处理不属于应用自动上传账本的功能。 7. 未成年人及政策更新 应用不专门面向儿童，也不主动收集儿童的身份资料。未成年人应在监护人指导下管理设备、备份和购买。 如果应用功能或资料处理方式发生变化，我们会更新本政策及日期，并在适用时通过应用或政策页面提示。隐私问题请联系：924323178@qq.com。 8. Apple Watch 伴侣应用 安装并打开伴侣应用后，配对的 iPhone 与 Apple Watch 通过系统 Watch Connectivity 交换本月收支与预算汇总、账户、分类和标签选项、已解锁 Pro 的消费复盘及储蓄目标摘要、主题、语言及金额隐藏偏好。隐藏金额后，新发送的汇总不包含金额。手表主动确认的收支记录先保存在手表，直到手机校验并保存成功后才确认同步；期间可能因连接、应用未打开或账户变化而等待。用于防止重复入账的随机请求编号与账本一起保存、备份，不用于跟踪身份。清空或恢复本机账本时会保留已处理编号，以免延迟消息重新入账。卸载应用可能移除未同步记录，卸载前请先同步。此过程不向开发者发送数据，不进行真实付款，也不提供手表端云备份或购买。 9. 桌面小组件 小组件通过仅供本应用及其组件扩展使用的本机 App Group 读取汇总快照，包含当前显示币种、主题、语言、更新时间、总预算与每日收支合计，不包含账户名称、备注或完整流水。开启隐藏金额后，新发布快照不包含任何金额。系统决定小组件刷新时机，旧快照可能短暂保留；打开应用可请求刷新。点击小组件仅打开收支日历或记账编辑器，不会自动保存账目。小组件不向开发者发送数据。 10. 多账本 账本名称及各账本账户、流水和规划保存在本机，切换不会合并数据。主题、语言和金额隐藏偏好共用。多账本 JSON 与云端完整备份包含全部账本，CSV 仅导出当前账本；恢复多账本备份会在确认后替换全部账本，旧单账本备份仅替换当前账本。与配对手表或本机小组件共享账本标识用于区分记录归属，未隐藏金额时可同时显示账本名称；隐藏时新快照不包含该名称。手表待同步记录保留原账本标识，不会因手机切换而改记到另一本。运营者不接收这些资料。 11. 票据、资产与退款报销 您主动选择的 JPG、PNG、PDF 票据原文件保存在本地流水中，随完整 JSON 和云备份保存；CSV 不含附件。每笔最多三份、每份最大 1 MiB。应用不进行 OCR 或向运营者上传票据。资产负债标记、退款和报销关联均在本地处理。配对手表可显示当前币种的净资产、负债和待报销汇总，不接收票据原文件。年度与月度分享图片由您预览和主动分享，请核对选中的金额字段及分享目标。删除本地票据不会自动删除此前导出的备份或分享副本。 12. 最新参考汇率 您打开参考汇率页面或刷新时，应用可直接向 Frankfurter（https://frankfurter.dev/，接口域名 api.frankfurter.dev）查询所选币种的综合参考汇率。服务及其网络基础设施会接收完成连接所需的网络信息（如 IP 地址）和币种对；输入金额在设备本地计算，不发送账单、账户名称、余额、备注或输入金额。数据日期、汇率及获取时间缓存在本机，与账本分开，不纳入账本备份；可在无网络时显示旧数据并标注。参考汇率通常每日更新，不是实时成交价，不会自动修改账本金额。接口服务详情请查看 https://frankfurter.dev/ 。 应用也可查询并在本机缓存该服务支持的货币清单；离线时使用缓存或应用内置清单。 13. 未完成的记账草稿 新建记账时，金额、账户与分类选择、日期、备注、标签和已选附件可暂存于设备本地，按账本隔离，不会自动生成流水。重新打开时由您选择恢复或丢弃；成功记账后清除对应草稿。草稿不属于 JSON、CSV 或云端账本备份，不发送给运营者、汇率服务或手表。草稿尚未落盘或设备存储故障时可能无法保留最新输入；卸载或清理应用资料也可能丢失草稿。编辑已有账目的离开确认不会自动修改原账目。 14. 本机显示偏好、备份状态与地区币种 参考汇率的最近货币对和收藏保存在本机，独立于账本备份，不保存输入金额。只有主动点击复制才会将参考结果、来源及日期写入系统剪贴板，请留意系统和其他应用的剪贴板访问。备份状态保存在本机，包括文件标识、时间、内容摘要和服务器地址的哈希，不保存云端凭据或额外上传账目；这是上次观察记录，不保证云端文件当前仍存在，分享成功不代表已保存。首次安装读取设备地区和系统货币配置以初始化本地账户，不请求定位权限、不使用GPS或IP定位，不覆盖已有账本币种。储蓄进度和预算提示在本机计算；在Pro已解锁且金额可见时，配对手表可收到待关注计划数量，不发送目标备注或附件。 15. 主动识图与一句话记账 仅在您选择单张图片并点击识别后，应用在设备上提取文字，供您核对金额、币种、账户和分类。图片和识别文字不上传给运营者；图片不会自动成为票据附件。识别可能出错，只有您在记账表单中确认保存才会入账。识别文字可进入您确认的备注及本机草稿。输入文字的解析也在本机进行；系统键盘听写由系统设置及其政策管理，应用不申请麦克风权限。快捷指令仅打开输入页，不自动记账。 iOS 快捷指令可由您主动传入记账文字。文字暂存于本机独立交接区，最多2000个UTF-16代码单元；15分钟后不再使用，并在下一次访问交接区时清理，接收后即删除。它不进入账本备份，不上传给运营者，不自动入账；账本切换后不沿用到另一账本。URL只包含随机请求编号，不包含文字、金额或账户名称。 16. Pro 试用到期提醒 仅当你主动选择提醒并允许系统通知时，应用才依据 StoreKit 验证的试用到期时间，在仍可提前 24 小时安排的情况下创建本机通知。提醒偏好独立保存在本机，不写入账本备份，不上传运营者；通知不含金额、账户或账目备注。提醒尽力送达，不保证准时，也不是 Apple 自动续订扣费的前提。通知权限被拒绝不影响购买。应用观察到取消续订、到期或撤销后会清除对应提醒；应用未运行时可能无法及时获知外部变更。请在 Apple 订阅设置管理或取消续订。
