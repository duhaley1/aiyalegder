## 常见问题 / FAQ

### 如何备份和恢复账本？

在「设置」中导出 JSON 完整备份，或进入「云端备份」手动保存到自己的 iCloud Drive / HTTPS WebDAV 文件夹。恢复前核对文件和预览，确认后会替换当前账本。CSV 用于表格查看；完整恢复请保留 JSON 备份。云备份不是实时账本同步。

Export a complete JSON backup in Settings, or manually use your own iCloud Drive / HTTPS WebDAV folder in Cloud Backup. Check the backup and preview before confirming restoration, which replaces the current ledger. CSV is for spreadsheet use; keep JSON for complete restoration. Cloud backup is not real-time ledger sync.

### iCloud 一直显示等待上传或下载怎么办？

确认设备已登录 Apple 账户并开启 iCloud Drive，检查网络和 iCloud 空间，再刷新备份历史。等待上传不代表已完成云备份。请保留本地 JSON 副本；不要在没有可用备份时卸载应用。

Make sure iCloud Drive is enabled, and check your connection and iCloud storage before refreshing backup history. A pending upload is not a completed cloud backup. Keep a local JSON copy and avoid uninstalling without a usable backup.

### 如何恢复哎呀 Pro？

使用购买时的 Apple 账户，进入「设置 → 哎呀 Pro → 恢复购买」。Pro 是非消耗型一次买断，无自动续费。恢复账本不会恢复或授予购买权益；购买状态由 Apple 已验证交易确认。若无法连接商店，请检查网络后重试。退款申请由 Apple 处理。

Use the Apple account that originally purchased Pro, then open Settings > Aiya Pro > Restore Purchases. Pro is a non-consumable one-time purchase with no automatic renewal. Restoring a ledger does not grant purchase access; Apple verifies ownership. Check your connection and retry if the store is unavailable. Apple handles refund requests.

### Pro 包含什么？

可选 Pro 解锁分类预算、周期账单和进阶报表。周期账单需要主动确认后入账；本地提醒需另外允许通知。基础记账、总预算、基础统计、导入导出、备份恢复、主题和常用模板继续免费。

Optional Pro unlocks category budgets, recurring bills and advanced reports. Bills are recorded only after confirmation; local reminders require notification permission. Core bookkeeping, overall budget, basic statistics, import/export, backups, themes and templates remain free.

### 数据是否加密？

当前账本及导出文件没有应用级加密，隐藏金额只遮挡界面。请保护设备并妥善保管备份。导入账单在本机解析，不连接银行或索取支付密码。

Ledger and exported files are not encrypted by the app. Hiding amounts only masks the screen. Protect your device and backups. Statement imports are parsed locally, with no bank connection or payment-password request.
