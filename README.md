## 备份与恢复 / Backups

「设置 → 数据管理」可导出完整 JSON 备份，或手动备份到自己的 iCloud Drive / HTTPS WebDAV 服务。恢复前核对文件与预览，确认后替换账本。云备份不等于实时同步，卸载前请保存可用备份。
Settings → Data management provides complete JSON backups and manual iCloud Drive / HTTPS WebDAV backups. Check the preview before restoring, which replaces ledger data. Cloud backups are not real-time sync; back up before uninstalling.

## 恢复 Pro / Restore Pro

使用原购买 Apple 账户，在「设置 → 哎呀 Pro → 恢复购买」操作。Pro 是可选非消耗型一次买断，无自动续费。恢复账本不授予购买权益；购买与退款由 Apple 处理。
Use the original Apple account in Settings → Aiya Pro → Restore Purchases. Pro is an optional non-consumable one-time purchase with no automatic renewal. Restoring ledger data does not grant Pro; Apple handles purchases and refunds.

## 手表 / Watch

打开配对的手机及手表应用，待同步记录会保留直到手机确认保存。卸载前先完成同步。
Open both paired apps. Pending entries remain until the phone confirms they were saved. Sync before uninstalling.

## 隐私 / Privacy

[简体中文](https://duhaley1.github.io/aiyalegder/privacy-policy.html) · [English](https://duhaley1.github.io/aiyalegder/privacy-policy-en.html)

账本与导出文件没有应用级加密，隐藏金额只遮挡界面。参考汇率仅供参考，不会修改账本金额。
Ledger/exported files are not app-encrypted. Hiding amounts only masks the UI. Reference rates never change ledger amounts.
